# 데이터 정책

커밋하기 전에 확인한다. 서버 저장소(`kumoh-academic-rag`)의 `docs/DATA_POLICY.md`와 같은 기준을 따른다.

## 저장소에 넣지 않는 것

- **학적 데이터** — 학번, 성명, 성적, 이수 학점, 장학 이력, 연락처. 테스트에도 명백히 가상인 값만 쓴다.
- **실제 학교 계정 정보** — 포털 비밀번호를 받거나 저장하는 화면을 만들지 않는다. 로그인은 서버의 시연 계정만 쓴다.
- **학칙·규정 원문** — 학교 저작물이다. 앱은 서버 API가 돌려준 인용만 보여 준다.
- **시크릿** — API 키, 서명 키(keystore), `.env`. 서명 키와 비밀번호는 GitHub 저장소 비밀값에만 둔다.

## 앱이 기기에 저장하는 것

- 대화 기록, 답변 모드, 언어 설정은 기기 안(localStorage)에만 둔다. 서버로 보내지 않는다.
- 사진은 질문을 보낼 때만 서버로 가고, 앱은 저장하지 않는다.
- 손글씨 그림과 인식 결과는 기기에 저장하거나 캐시하지 않는다. 사용자가 입력창에서 직접 보낸 질문은 일반 대화 기록과 같은 기준으로 저장한다.
- 서비스 워커는 화면 파일만 캐시하고 API 응답은 캐시하지 않는다.
