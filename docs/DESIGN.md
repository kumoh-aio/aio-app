하늘색 채움 `#00A3D9`, 다크 모드의 강조색, 노랑, 코랄 위에는 네이비 글자 `#0A2540`을 쓴다. 본문 대비는 4.5:1 이상으로 맞춘다. 조작 영역은 44px 이상, 컨트롤 경계 대비는 3:1 이상으로 잡고 키보드 포커스는 2px 실선으로 표시한다.

더보기의 화면 설정에서 색 모드와 입체 효과를 각각 고른다. 기본값은 시스템 색과 기본 효과다. 음각양각에서는 불투명 단색 면을 바탕으로 홈 타일·카드·아래 탭 막대에 볼록한 그림자를, 입력창과 선택한 옵션에 오목한 그림자를 준다. 움직임 줄이기를 켜면 애니메이션과 전환을 끈다.

### 시안을 옮길 때 지킬 것

- Stitch가 지어낸 요건(예: 특정 어학 점수, 특정 비교과 제도)은 쓰지 않는다. 졸업 요건과 규정은 서버 API가 돌려준 값만 보여 준다.
- 숫자 예시(108/130 등)는 시연 계정 응답으로 채운다.
- 테크모 그림은 서버 저장소의 `api/app/chat_web/art/techmo-sprite.png`(192px 칸, 8열)를 쓴다.
- 글꼴은 기기 글꼴(Pretendard, Apple SD Gothic Neo, 맑은 고딕, Noto Sans KR 순)이고 외부 글꼴을 내려받지 않는다.
