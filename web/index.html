홈 화면에 아이오 설치하기

브라우저 메뉴에서 홈 화면에 추가하면 앱처럼 바로 열려요. 한 번 연 화면은 인터넷 없이도 열리지만, 답변과 일정은 연결이 필요해요.

Android · Chrome

  1. Chrome에서 아이오 주소를 열어요.
  2. 오른쪽 위 ⋮ 메뉴를 눌러요.
  3. "홈 화면에 추가"나 "앱 설치"를 고르고 "설치"를 눌러요.

iPhone · Safari

  1. Safari에서 아이오 주소를 열어요.
  2. 공유 버튼(네모에서 화살표가 나온 모양)을 눌러요. 안 보이면 주소창 옆 ··· 메뉴에서 찾아요.
  3. "홈 화면에 추가"를 고르고 오른쪽 위 "추가"를 눌러요.

홈 화면의 아이오 아이콘을 누르면 주소창 없이 홈 탭부터 열려요.
